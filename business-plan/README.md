# Story Lens Business Plan Package

이 폴더는 `Story Lens` 앱을 기반으로 작성한 한글 사업계획서 패키지입니다.

대상
- 이천시청
- 이천시 내 장애인 협회 및 유관 단체
- 복지관, 평생교육 기관, 문화예술 협력 기관

구성 파일
- `index.html` : 제안용 허브 화면
- `style.css` : 허브 화면 스타일
- `01-proposal.md` : 상세 사업계획서
- `02-budget.md` : 세부 예산안
- `03-summary.md` : 제안요약서

권장 확인 순서
1. `index.html`
2. `03-summary.md`
3. `01-proposal.md`
4. `02-budget.md`

예산 관련 참고
- 본 문서의 금액은 **연간 시범사업(안)** 기준 추정치입니다.
- 실제 집행 시 참여 인원, 운영 회차, 지역 이동 거리, 인건비 기준, 인쇄 수량에 따라 조정할 수 있습니다.
