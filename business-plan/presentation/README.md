# Story Lens Presentation Package

이 폴더는 이천시청 및 장애인 협회 제안용 발표자료를 담습니다.

구성
- `generate_story_lens_ppt.py` : 발표자료 생성 스크립트
- `story-lens-public-proposal.pptx` : 생성된 발표자료 파일

참고 자산
- 앱 스크린샷: `business-plan/assets/screens/`
- 사업계획서 원문: `business-plan/01-proposal.md`
- 예산안: `business-plan/02-budget.md`
- 요약서: `business-plan/03-summary.md`

디자인 참고
- `.opencode/skills/pptx-design-styles/`
- 적용 방향: `Swiss International` + `Nordic Minimalism` 기반, `Claymorphism` 포인트 혼합
