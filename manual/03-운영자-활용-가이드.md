# Story Lens 운영자 활용 가이드

## 1. 이 문서의 목적

이 문서는 Story Lens를 **수업, 프로그램, 활동 운영 도구**로 활용하려는 선생님과 운영자를 위한 안내서입니다.

주요 목표는 다음과 같습니다.

- 참여자가 스스로 촬영과 편집을 이어갈 수 있게 돕기
- 월별 일정과 현장 활동을 사진 기록으로 연결하기
- 결과물을 수업 회고, 전시, 발표 자료로 활용하기

---

## 2. 운영자 관점에서 중요한 기능

### 2.1 홈 화면 기능
- 사진 촬영 시작
- 앨범 사진 불러오기
- 보관함 진입
- 사진집 만들기
- 월별 일정 보기

### 2.2 일정 관리 화면
- 월별 활동 카드 확인
- 날짜, 장소, 설명 확인
- 키워드와 미션 확인
- 글쓰기용 주제/이야기 아이디어 확인

### 2.3 보관함과 상세 화면
- 사진, 글, 음악 결과물 확인
- 다시 편집/글 수정/음악 생성 연결

### 2.4 사진집 만들기
- 프로그램 결과물을 한 번에 PDF로 정리
- 템플릿별 분위기 선택 가능

---

## 3. 추천 운영 흐름

## 3.1 수업 전 준비

1. `월별 일정 보기`에서 당월 활동 내용을 확인합니다.
2. 오늘 사용할 키워드와 미션을 미리 정리합니다.
3. 참여자에게 제시할 질문을 준비합니다.
   - 예: “오늘 가장 먼저 찍고 싶은 장면은 무엇인가요?”
   - 예: “이 장소에서 가장 기억에 남는 색은 무엇인가요?”

---

## 3.2 현장 활동 중

### 촬영 단계
- 참여자가 스스로 사진을 찍도록 먼저 시도하게 합니다.
- 처음부터 완벽한 구도를 요구하기보다 여러 장 촬영하게 돕습니다.

### 선택 단계
- 사진 선택 화면에서 가장 마음에 드는 장면을 고르게 합니다.
- 추천 주제를 보여주되, 직접 주제를 말하거나 입력할 수 있게 유도합니다.

### 편집 단계
- “어떤 느낌으로 바꾸고 싶은지”를 먼저 물어보세요.
- 슬라이더는 하나씩 바꿔보게 하면서 결과 차이를 스스로 느끼게 하는 것이 좋습니다.

---

## 3.3 수업 후 정리

1. 보관함에서 결과를 함께 확인합니다.
2. 사진 상세 화면에서 글과 음악까지 연결합니다.
3. 여러 장이 쌓이면 사진집 만들기로 PDF를 제작합니다.
4. 학기 말/프로그램 말에는 사진집 또는 대표 결과물을 발표 자료로 활용합니다.

---

## 4. 참여자 지원 팁

### 4.1 질문 방식
- “무엇이 보였나요?”
- “어떤 기분이었나요?”
- “이 장면을 다른 사람에게 소개한다면 뭐라고 말하고 싶나요?”

이 질문들은 글쓰기와 음악 생성 단계까지 자연스럽게 연결됩니다.

### 4.2 도와줄 때 유의할 점
- 결과를 대신 정해주기보다 선택지를 좁혀 주세요.
- 버튼을 대신 눌러주기보다 어디를 누르면 되는지 먼저 말로 안내해 주세요.
- 편집 결과의 정답을 제시하기보다 사용자의 감정을 우선으로 존중해 주세요.

### 4.3 음악 생성 안내
- AI 음악은 생성 시간이 길 수 있습니다.
- 바로 안 나오더라도 실패가 아니라 대기 상태일 수 있으니, `결과 확인` 흐름을 안내해 주세요.

---

## 5. 월별 일정 화면 활용법

현재 일정 화면에는 월별 활동 예시가 정리되어 있습니다.

화면에서 확인할 수 있는 요소
- 활동 제목
- 장소
- 날짜
- 사진 미션
- 추천 주제
- 추천 이야기 힌트

활용 예시
- 수업 시작 전에 오늘의 활동 소개 자료처럼 보여주기
- 촬영 과제를 정할 때 미션 1~2개를 먼저 안내하기
- 글쓰기 시간에 `myTopic`, `myStory`를 대화 시작 질문으로 활용하기

---

## 6. 결과물 정리 전략

### 전략 A. 개인 결과물 중심
- 각 참여자가 1장의 대표 사진을 완성
- 사진 + 글 + 음악을 하나의 기록으로 저장

### 전략 B. 월별 포트폴리오 중심
- 한 달 활동 사진 3~5장 선택
- 사진집 PDF로 묶어 월별 결과물 제작

### 전략 C. 프로그램 전체 회고 중심
- 3월부터 12월까지 대표 사진 선별
- 사진집으로 연간 활동집 제작

---

## 7. 운영자 체크리스트

### 수업 전
- [ ] 로그인 상태 확인
- [ ] 카메라/인터넷 환경 확인
- [ ] 오늘의 일정/미션 확인
- [ ] 결과물 저장 방법 안내 준비

### 수업 중
- [ ] 참여자가 직접 사진 선택을 해보게 하기
- [ ] 편집 시 필터와 슬라이더를 순서대로 안내하기
- [ ] 글쓰기 전 사진 느낌을 한 문장으로 말하게 하기
- [ ] 음악 생성은 시간이 걸릴 수 있음을 먼저 안내하기

### 수업 후
- [ ] 보관함에서 결과 확인
- [ ] 대표 결과물 선별
- [ ] 사진집 PDF 제작 여부 검토

---

## 8. 자주 묻는 운영 질문

### Q1. AI 기능이 실패하면 수업이 멈추나요?
아니요. 글 초안은 보조 방식으로 이어갈 수 있고, 음악도 다시 확인 흐름을 활용할 수 있습니다.

### Q2. 한 번에 모든 기능을 써야 하나요?
아니요. 촬영 → 편집까지만 진행해도 충분합니다. 글쓰기와 음악은 다음 단계로 이어갈 수 있습니다.

### Q3. 사진집은 언제 쓰면 좋나요?
한 번의 활동보다, 여러 장의 결과가 쌓였을 때 더 가치가 큽니다. 월별 또는 학기말 정리에 적합합니다.

---

## 9. 운영자에게 추천하는 활용 방식

가장 추천하는 활용법은 아래 순서입니다.

1. 일정 보기로 오늘 활동의 맥락 설명
2. 사진 촬영/선택으로 주체적 시작
3. 편집 단계에서 감정 중심 표현 유도
4. 글쓰기에서 말 → 문장 → 초안 흐름으로 확장
5. 음악으로 분위기 완성
6. 보관함과 사진집으로 결과를 남김

이 구조는 단순히 사진을 꾸미는 활동을 넘어, **자신의 시선을 기록하고 정리하는 경험**으로 이어집니다.
