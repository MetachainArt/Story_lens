# Story Lens 사용자 매뉴얼

## 1. 시작하기 전에

### 1.1 준비물
- 카메라가 있는 기기 또는 사진이 저장된 스마트폰/PC
- 인터넷 연결
- 로그인 가능한 계정

### 1.2 처음 사용할 때 확인할 것
- 카메라 사용 시 브라우저 권한 허용
- 사진 업로드 시 이미지 파일 선택 가능 여부 확인
- AI 기능은 네트워크 상태에 따라 시간이 다소 걸릴 수 있음

---

## 2. 전체 사용 흐름

1. 로그인
2. 홈에서 사진 찍기 또는 앨범에서 불러오기
3. 사진 선택 후 주제 정하기
4. 사진 편집하기
5. 저장 완료 화면 확인
6. AI 글쓰기 이어가기
7. AI 음악 만들기
8. 보관함에서 다시 보기
9. 여러 장을 모아 사진집 PDF 만들기

---

## 3. 로그인하기

### 화면 위치
- `로그인` 화면

### 할 수 있는 일
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼으로 앱 시작

### 안내 포인트
- 이메일과 비밀번호가 비어 있으면 진행되지 않습니다.
- 입력이 잘못되면 오류 메시지가 표시됩니다.

---

## 4. 홈 화면 사용법

### 홈에서 보이는 주요 버튼
- `사진 찍기`
- `앨범에서 불러오기`
- `내 사진 보기`
- `사진집 만들기`
- `월별 일정 보기`
- `로그아웃`

### 추천 사용법
- 새로운 활동을 시작할 때는 `사진 찍기`
- 이미 찍어 둔 사진으로 시작할 때는 `앨범에서 불러오기`
- 이전 결과를 다시 보고 싶을 때는 `내 사진 보기`

---

## 5. 사진 촬영하기

### 5.1 카메라 화면에서 가능한 일
- 전면/후면 카메라 전환
- 사진 촬영
- 여러 장 촬영 후 선택 화면으로 이동
- 기기 앨범 사진 불러오기

### 5.2 촬영 팁
- 피사체가 중앙에 오도록 맞추면 이후 편집이 쉽습니다.
- 여러 장 찍고 나중에 고르는 것이 더 편합니다.

### 5.3 문제 해결
- 카메라가 켜지지 않으면 브라우저 권한을 확인하세요.
- 권한 거부 시 홈으로 돌아가 앨범 사진 업로드로도 시작할 수 있습니다.

---

## 6. 사진 선택 및 주제 정하기

### 화면 위치
- `사진 선택`

### 할 수 있는 일
- 좌우로 사진 넘기기
- 원하는 사진 1장 고르기
- 추천 주제 선택
- 직접 주제 입력
- `이 사진 편집하기`로 다음 단계 이동

### 추천 주제는 어디서 오나요?
- 월별 일정/세션에 연결된 키워드에서 가져옵니다.
- 프로그램 운영 시 일정 주제와 연결하기 좋습니다.

### 사용 팁
- 주제를 정해두면 이후 글쓰기와 음악 만들기가 더 자연스러워집니다.

---

## 7. 사진 편집하기

### 화면 위치
- `편집` 화면

### 7.1 기본 편집 기능
- 필터 선택
- 밝기 조절
- 대비 조절
- 채도 조절
- 온도 조절
- 선명도 조절

### 7.2 추가 조작 기능
- 확대/축소
- 손가락 또는 드래그로 화면 이동
- 회전
- 좌우 반전

### 7.3 저장 후 흐름
- 편집을 마치면 완료 화면으로 이동합니다.
- 완료 화면에서는 다음을 선택할 수 있습니다.
  - 홈으로
  - 다시 편집
  - 글로 이어쓰기

### 편집 팁
- 먼저 필터를 고른 뒤 세부 슬라이더를 조정하면 더 쉽습니다.
- 확대 상태에서는 사진 일부를 세밀하게 보고 조정할 수 있습니다.

---

## 8. AI와 함께 글쓰기

### 화면 위치
- `글쓰기 시작`

### 할 수 있는 일
- 사진 주제 확인
- 사진을 보며 한 줄 느낌 입력
- `AI 글 생성`으로 초안 받기
- 받은 초안을 직접 수정하기
- 최종 글 저장하기

### 어떻게 쓰면 좋을까요?
- 먼저 사진을 보고 떠오르는 생각을 한 줄로 적습니다.
- 예시: `햇살이 따뜻해서 마음이 편안했어`
- AI는 이 입력을 바탕으로 최대 5줄 초안을 제안합니다.

### 주의할 점
- 네트워크 상태에 따라 AI 초안 생성이 실패할 수 있습니다.
- 실패하더라도 보조 초안이 제공될 수 있습니다.

---

## 9. AI 음악 만들기

### 화면 위치
- `음악 만들기`

### 선택 가능한 스타일
- 발라드
- 재즈
- 힙합
- 인디 팝
- 로파이
- 어쿠스틱 포크
- 클래식
- 시네마틱

### 진행 방법
1. 원하는 스타일 선택
2. `AI 음악 만들기` 버튼 누르기
3. 진행 상태 메시지 확인
4. 음악이 준비되면 재생 목록 확인

### 꼭 알아둘 점
- 음악 생성은 짧게 끝나지 않을 수 있습니다.
- 현재 안내 기준은 **최대 10분**입니다.
- 오래 걸리면 `결과 확인` 버튼으로 다시 조회할 수 있습니다.

### 음악이 완성되면
- 곡 재생 가능
- 보관함 상세 화면에서도 다시 재생 가능

---

## 10. 보관함 사용법

### 10.1 보관함 목록 화면
- 저장된 사진 확인
- 사진 삭제
- 사진 상세 보기로 이동

### 10.2 상세 화면에서 가능한 일
- 사진 크게 보기
- 주제와 날짜 확인
- 작성한 글 읽기
- 저장된 음악 재생
- 다시 편집
- 글쓰기/글 수정
- 음악 만들기

### 보관함 활용 팁
- 글이 없는 사진은 상세 화면에서 바로 글쓰기로 이어갈 수 있습니다.
- 음악이 연결된 사진은 상세 화면에서 바로 들을 수 있습니다.

---

## 11. 사진집 만들기

### 화면 위치
- 홈 → `사진집 만들기`

### 진행 순서
1. 사진집에 넣을 사진 선택
2. 사진집 제목 입력
3. 템플릿 선택
4. 미리보기 확인
5. PDF 다운로드

### 제공 템플릿 예시
- 미니멀
- 매거진
- 폴라로이드
- 시네마틱
- 다이어리
- 갤러리

### 사용 팁
- 사진집은 여러 장을 묶어 한 번에 결과물로 만들 때 유용합니다.
- 사진 수업 결과 정리, 발표 자료, 전시 준비용으로 활용하기 좋습니다.

---

## 12. 월별 일정 보기

### 화면 위치
- 홈 → `월별 일정 보기`

### 볼 수 있는 정보
- 월별 활동 제목
- 장소
- 설명
- 날짜
- 관련 키워드
- 활동 미션
- 내가 쓸 수 있는 주제/이야기 힌트

### 활용법
- 수업 전 오늘의 활동 주제를 미리 확인
- 사진 주제 고를 때 아이디어 얻기
- 프로그램 회고 자료로 사용

## 13. 자주 생기는 상황과 해결 방법

### 13.1 카메라가 열리지 않아요
- 브라우저의 카메라 권한을 허용했는지 확인하세요.
- 계속 안 되면 `앨범에서 불러오기`로 시작할 수 있습니다.

### 13.2 AI 글 생성이 실패했어요
- 잠시 후 다시 시도하세요.
- 네트워크가 불안정하면 보조 초안이 대신 들어갈 수 있습니다.

### 13.3 AI 음악 생성이 오래 걸려요
- 10분 정도 기다릴 수 있습니다.
- 중간에 끝나지 않아도 `결과 확인`으로 다시 조회해 보세요.

### 13.4 보관함에 사진이 안 보여요
- 로그인 상태와 네트워크를 확인하세요.
- 로컬 저장만 된 경우 기기 저장/브라우저 저장 상태에 따라 달라질 수 있습니다.

### 13.5 PDF가 마음에 들지 않아요
- 사진집 템플릿을 바꿔 다시 미리보기해 보세요.
- 들어갈 사진 수를 줄이면 더 깔끔한 결과가 나올 수 있습니다.
