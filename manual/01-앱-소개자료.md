# Story Lens 앱 소개자료

## 1. 앱 한 줄 소개

**Story Lens는 사진을 찍고, 다듬고, 글과 음악으로 이어서 하나의 이야기로 완성하는 접근성 중심 스토리텔링 앱입니다.**

---

## 2. 왜 이 앱이 필요한가

Story Lens는 단순한 사진 편집 앱이 아니라, 참여자가 **자신의 시선으로 찍은 사진을 스스로 표현할 수 있도록 돕는 도구**를 목표로 합니다.

이 앱이 해결하려는 문제는 다음과 같습니다.

- 사진 편집 도구가 너무 복잡해서 혼자 사용하기 어렵다.
- 촬영 이후의 활동이 끊기기 쉬워서 기록이 결과물로 남지 않는다.
- 사진, 글, 음악, 인쇄용 결과물이 서로 분리되어 있어 흐름이 끊긴다.
- 수업 현장에서 선생님이 모든 편집을 대신해야 하는 구조가 반복된다.

Story Lens는 이 문제를 **큰 버튼, 단순한 흐름, 단계별 결과 축적**으로 해결합니다.

---

## 3. 대상 사용자

### 3.1 참여자
- 자신의 사진을 직접 고르고 꾸며보고 싶은 아동/청소년/성인 사용자
- 복잡한 편집 프로그램보다 직관적인 단계형 앱이 필요한 사용자
- 사진에 감정과 이야기를 더해보고 싶은 사용자

### 3.2 선생님/활동가
- 촬영 활동, 사진 수업, 기록 프로그램을 운영하는 분
- 월별 미션이나 현장 수업을 바탕으로 결과물을 정리해야 하는 분
- 참여자의 작업 과정을 쉽게 안내하고 싶으신 분

### 3.3 협력 기관 및 내부 팀
- 프로그램 소개 자료가 필요한 복지관, 학교, 문화기관, 프로젝트 파트너
- 사진 결과물을 전시, 발표, 회고 자료로 정리해야 하는 실무자

---

## 4. 핵심 가치

### 4.1 접근성 있는 창작 경험
- 큰 버튼과 명확한 화면 구조
- 단계별 안내 중심의 사용 흐름
- 사진 편집 초보자도 따라가기 쉬운 구성

### 4.2 사진 이후의 확장성
- 사진 편집으로 끝나지 않고 글쓰기와 음악 생성으로 연결
- 한 장의 사진을 감정과 서사가 있는 결과물로 발전시킴

### 4.3 기록의 축적
- 보관함에서 사진을 다시 확인하고 수정 가능
- 사진집(PDF)으로 결과물을 정리하고 공유 가능

### 4.4 프로그램 운영 친화성
- 월별 일정/미션과 연결 가능
- 활동 주제와 사진 기록을 함께 축적 가능

---

## 5. 현재 구현 기준 주요 기능

### 5.1 사진 촬영 및 불러오기
- 홈에서 카메라 촬영 시작
- 앨범 사진 업로드
- 여러 장 촬영 후 선택 화면으로 이동

### 5.2 사진 선택과 주제 정리
- 촬영한 사진을 넘겨보며 1장을 고름
- 추천 주제를 선택하거나 직접 입력 가능

### 5.3 사진 편집
- 필터 적용
- 밝기, 대비, 채도, 온도, 선명도 조절
- 확대/축소, 이동, 회전, 좌우 반전 지원
- 편집 후 저장

### 5.4 AI 글쓰기
- 사진 주제를 바탕으로 글쓰기 시작
- 한 줄 느낌을 입력하면 AI가 최대 5줄 초안을 제안
- 초안을 바탕으로 사용자가 자유롭게 수정

### 5.5 AI 음악 만들기
- 발라드, 재즈, 힙합, 인디 팝, 로파이, 어쿠스틱 포크, 클래식, 시네마틱 스타일 제공
- 사진과 글의 분위기를 바탕으로 음악 생성
- 생성 시간이 길어질 경우 결과를 다시 확인하는 흐름 제공

### 5.6 보관함과 상세 보기
- 저장된 사진 목록 확인
- 상세 페이지에서 사진, 글, 음악 확인
- 상세 화면에서 다시 편집/글쓰기/음악 만들기 가능

### 5.7 사진집 만들기
- 보관함 사진 여러 장 선택
- 템플릿 선택
- 미리보기 확인 후 PDF로 내보내기

### 5.8 월별 일정 보기
- 월별/연간 활동 일정 확인
- 미션, 주제, 글감 아이디어 확인

---

## 6. 대표 사용 시나리오

### 시나리오 A. 참여자 중심 흐름
1. 사진을 찍는다.
2. 마음에 드는 사진을 하나 고른다.
3. 필터와 슬라이더로 사진을 다듬는다.
4. 사진에 대한 생각을 짧게 적고 AI 초안을 받는다.
5. 사진에 어울리는 음악을 만든다.
6. 결과를 보관함에 저장하고 나중에 다시 본다.

### 시나리오 B. 프로그램 운영 흐름
1. 월별 일정에서 오늘의 장소와 주제를 확인한다.
2. 참여자가 현장에서 사진을 찍는다.
3. 수업 종료 전 편집과 글쓰기를 마친다.
4. 결과물을 보관함에서 확인한다.
5. 학기 말에는 사진집 PDF로 묶어 전시나 발표 자료로 활용한다.

---

## 7. 이 앱이 주는 기대 효과

### 참여자에게
- 내가 찍은 사진이 하나의 이야기로 완성되는 경험
- 편집, 글, 음악까지 스스로 이어보는 창작 경험
- 결과물을 다시 보고 남길 수 있는 기록 경험

### 선생님에게
- 활동 흐름을 하나의 앱에서 연결 가능
- 결과물을 빠르게 모아서 정리 가능
- 수업 현장에서 설명해야 할 단계가 명확함

### 기관/프로젝트에게
- 참여형 프로그램의 결과가 더 잘 남음
- 소개 자료와 전시 자료로 확장 가능
- 사진 기반 교육/활동의 가시성이 좋아짐
