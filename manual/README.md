# Story Lens Manual

이 폴더는 `Story Lens` 앱을 소개하고 실제 사용 흐름을 설명하는 한글 메뉴얼 패키지입니다.

구성 파일
- `index.html` : 소개 자료 + 메뉴얼 허브 화면
- `style.css` : 메뉴얼 허브 스타일
- `01-앱-소개자료.md` : 앱 소개, 핵심 가치, 주요 기능 요약
- `02-사용자-매뉴얼.md` : 일반 사용자 기준 상세 사용 방법
- `03-운영자-활용-가이드.md` : 선생님/운영자 관점 활용 가이드

권장 사용 방법
1. 먼저 `manual/index.html`을 열어 전체 소개를 살펴봅니다.
2. 자세한 내용이 필요하면 각 Markdown 문서를 순서대로 확인합니다.

대상 독자
- 사진을 찍고 기록하고 싶은 참여자
- Story Lens 수업을 운영하는 선생님/활동가
- 앱 소개 자료가 필요한 협력 기관 및 내부 구성원
